# 🎈 ToddlerPlayHub

**ToddlerPlayHub** es una colección de aplicaciones web interactivas y ligeras diseñadas para que los niños exploren el teclado físico, reconozcan letras/números y desarrollen habilidades motrices mediante retroalimentación visual y auditiva.

---

## 🎮 Actividades Incluidas

1. **🔤 Keyboard Play:**
   - Muestra letras gigantes y colores vibrantes en pantalla.
   - Genera notas musicales tipo xilófono con la Web Audio API.
   - Animaciones de confeti y burbujas.

2. **⚡ Pokémon Box:**
   - Estética retro inspirada en los juegos de Game Boy Advance.
   - Genera un Pokémon aleatorio por cada letra presionada (A-Z).
   - Fondos de caja de PC dinámicos y efectos de sonido estilo chiptune.

---

## 🚀 Tecnologías Utilizadas

- **HTML5 & CSS3:** Interfaces responsivas y animaciones sin librerías externas.
- **JavaScript (ES6+):** Lógica del evento `keydown` y manipulación del DOM.
- **Web Audio API:** Sintetizador de tonos y efectos de sonido retro sin archivos de audio pesados.

---

## 💡 Cómo Usarlo

Simplemente abre el archivo `index.html` en cualquier navegador moderno o visita la versión desplegada en **GitHub Pages**.
